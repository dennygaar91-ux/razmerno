# Manual QA Matrix — «Размерно»

Дата: 2026-06-13
Тип: QA documentation.

## Цель

Матрица нужна для ручной проверки проекта перед крупными этапами разработки.

## Правила

- Не отмечать проверку как пройденную, если она не выполнялась.
- Отдельно фиксировать blocked-сценарии.
- Для protected zones нужна отдельная проверка.

## Базовая матрица

| Зона | Проверка | Статус |
|---|---|---|
| Landing | Главная открывается | todo |
| Landing | CTA ведет в ожидаемый сценарий | todo |
| Constructor | Конструктор открывается | todo |
| Constructor | Размеры изменяются без ошибки приложения | todo |
| Constructor | Наполнение отображается предсказуемо | todo |
| Constructor | Материалы отображаются | todo |
| 3D/Fallback | 3D-сцена не блокирует сценарий | todo |
| Checkout | Поля заявки отображаются | todo |
| Checkout | Warning/error состояния понятны | todo |
| Admin | Админка не затронута документационным этапом | todo |
| API | API не затронут документационным этапом | todo |
| Pricing | Расчет не затронут документационным этапом | todo |

## Использование

Эта матрица не заменяет автоматические тесты. Она дополняет CI для пользовательских сценариев.
