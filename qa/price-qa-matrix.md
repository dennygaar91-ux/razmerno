# Price QA Matrix — «Размерно»

Дата: 2026-06-13
Тип: QA documentation.

## Цель

Матрица фиксирует проверки цены без изменения pricing engine.

## Важное правило

Этот документ не меняет расчет стоимости. Он только описывает будущие проверки.

## Базовые сценарии

| ID | Сценарий | Ожидаемый принцип | Статус |
|---|---|---|---|
| P01 | Минимальный шкаф | Цена считается единым pricing engine | todo |
| P02 | Изменение ширины | Цена пересчитывается после изменения размера | todo |
| P03 | Изменение высоты | Цена пересчитывается после изменения размера | todo |
| P04 | Изменение глубины | Цена пересчитывается после изменения размера | todo |
| P05 | Добавление секций | Цена остается согласованной между UI и order payload | todo |
| P06 | Добавление полок | Цена учитывает изменение состава | todo |
| P07 | Добавление ящиков | Цена учитывает изменение состава | todo |
| P08 | Выбор материала | Цена соответствует выбранному материалу | todo |
| P09 | Доставка включена | Доставка считается отдельно от мебели | todo |
| P10 | Сборка включена | Сборка считается отдельно от доставки | todo |
| P11 | Checkout total | Итоговая сумма соответствует детализации | todo |

## Acceptance

Price QA считается выполненным только после запуска сценариев и фиксации результата в отчете.
