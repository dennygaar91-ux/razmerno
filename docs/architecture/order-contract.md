# Order Contract — «Размерно»

Дата: 2026-06-13
Тип: architecture contract documentation.

## Цель

Документ фиксирует границы order contract без изменения order flow.

## Принципы

- Заявка создается только из валидной конфигурации.
- Клиентские данные обязательны только там, где это требуется checkout-сценарием.
- Ошибка отправки клиентского письма не должна автоматически означать провал заявки, если заявка менеджеру создана и сохранена по правилам проекта.
- Повторная отправка должна быть защищена от случайного дубля.
- Runtime-поведение не меняется в рамках этого документа.

## Protected scope

Без отдельного задания нельзя менять:

- форму заявки;
- validation order payload;
- отправку заявки;
- email delivery;
- storage order records;
- idempotency logic;
- checkout total behavior.

## Acceptance

Этот документ фиксирует рамку. Подробный payload contract должен быть добавлен отдельным этапом после стабилизации CI.
