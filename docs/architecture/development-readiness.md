# Development Readiness — Razmerno

Date: 2026-06-13
Type: architecture note.

## Goal

Define the readiness gate before new constructor development.

## Required before implementation

- Architecture docs exist in GitHub.
- Protected zones are documented.
- Testing strategy exists.
- QA matrices exist.
- CI workflow is stabilized.
- Development task is documented.

## Not included

This note does not change code, UI, API, backend, pricing, checkout, admin, export or 3D behavior.

## Acceptance

Development can start only after the architecture block is verified and CI status is known.
