# Roadmap — «Размерно»

Дата актуализации: 2026-06-10

## MVP

- 3D-first конструктор по умолчанию.
- 4 шага: Размеры / Наполнение / Материалы / Заявка.
- Выбор типа мебели: шкаф / тумба / комод с безопасной логикой MVP.
- Габариты: ширина / высота / глубина с validation.
- Секции по ширине, минимум 200 мм на секцию.
- Зоны внутри секций.
- Управление наполнением через выбранную зону.
- Полки, ящики, штанга в выбранной зоне.
- Фасады на уровне секции в обычном режиме.
- Фасады по зонам в точной настройке.
- Ручки / без ручек.
- Реальные текстуры материалов.
- Material zoom-preview.
- 2D fallback без полноценного инженерного чертежа.
- Точная цена.
- Checkout внутри конструктора.
- Доставка и сборка в checkout.
- Reset без autosave.
- Error/warning/info validation UX.
- Рабочий production-safe order flow.
- Базовая accessibility устойчивость.
- Browser E2E в CI/локально.

## Post MVP

- Полный визуальный QA финальной сборки.
- CSS cleanup после визуального QA.
- Удаление legacy после миграции тестов.
- Глубокая Three.js performance optimization.
- Улучшение 2D blueprint readability.
- Более точная библиотека фурнитуры Hettich/Firmax.
- Production warnings/admin layer depth.
- PDF-смета/HTML attachments.
- Admin order detail page refinement.
- Клиентские документы/инструкции.
- Яндекс.Метрика events audit.

## Future

- Полноценный инженерный 2D-чертёж.
- Exploded view.
- Assembly mode.
- Animated assembly.
- AI assembly system.
- B2B mode.
- Автоматизация БАЗИС/.b3d.
- Кухни и сложные мебельные категории.
- Mobile bottom sheet constructor.
- Cloud drafts/history/account.
- CRM/logistics integrations.
