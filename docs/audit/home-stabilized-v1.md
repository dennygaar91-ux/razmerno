# Stage: home-stabilized-v1

Дата: 2026-06-01

## Цель
Вернуть главную страницу к стабильной визуальной базе и внедрить только согласованные улучшения: чистая структура, мягкая живость, понятный блок стоимости, корректные ссылки и отсутствие блоков, которые ломали ритм.

## Что сделано
- Главная пересобрана заново внутри `src/StaticDesignPages.tsx`, только для `pages.home`.
- Остальные страницы, backend, pricing, delivery, admin и production-логика не изменялись.
- Убрана поехавшая наслоенная структура главной.
- Оставлены 7 основных смысловых блоков:
  1. Hero.
  2. Как это работает.
  3. Сколько примерно стоит.
  4. Что получите в комплекте.
  5. Что можно создать.
  6. Если проект сложнее.
  7. FAQ + final CTA + footer.
- Вторичная кнопка в Hero переименована в «Как это работает», чтобы не обещать видео, которого пока нет.
- Карточки «Как это работает» ведут на профильные страницы: `/measurements`, `/configurator`, `/materials`, `/assembly`.
- Блок «Сначала согласование, потом запуск» не оставлен отдельной тяжёлой секцией: смысл перенесён в FAQ и final CTA.
- Добавлен компактный блок ориентировочной стоимости.
- Добавлены лёгкие CSS-анимации: reveal, hover lift, float hero image/chips.
- Добавлен `prefers-reduced-motion` fallback.

## Что не сделано
- Не добавлялись тяжёлые JS-анимации, parallax, count-up, Lottie или новая 3D-анимация.
- Не трогался конструктор и backend.
- Не делалась полная интеграция нового UI со store/pricing/order flow.

## Риски
- Главная по-прежнему static UI внутри `dangerouslySetInnerHTML`. Это принято как промежуточный способ визуальной стабилизации.
- Следующий этап должен идти по блокам, без массового внедрения всех предложений Claude сразу.
