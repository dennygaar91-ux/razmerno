# Размерно — constructor scene fill preview v18

## Что сделано

Правое SVG-превью конструктора теперь визуально связано с выбранным наполнением.

## Изменения

### SVG-модель

- Убрана статичная внутренняя схема.
- Количество вертикальных секций теперь зависит от `sections`.
- Визуальное наполнение теперь зависит от `fill`:
  - `shelves` — показываются полки и storage boxes;
  - `drawers` — показываются блоки ящиков;
  - `rod` — показывается штанга и условные hanger shapes.
- Число горизонтальных уровней для полок зависит от `compartments`.

### UI

- Добавлен fill badge внутри сцены:
  - выбранное наполнение;
  - количество секций;
  - количество отсеков.
- Footer сцены теперь показывает выбранное наполнение рядом с материалом и ручками.

### Новые/изменённые классы

- `.rzm-svg-shelf`
- `.rzm-svg-line--soft`
- `.rzm-svg-fill-group`
- `.rzm-svg-storage-box`
- `.rzm-svg-hanger`
- `.rzm-model-fill-badge`

## Что не трогалось

- backend/API;
- pricing engine;
- order flow;
- production preview adapter;
- Zustand-store;
- production geometry;
- admin;
- маршруты.

## Результат

Клиент теперь видит, что выбор «Полки / Ящики / Штанга» меняет не только стоимость и payload, но и визуальную схему шкафа.
