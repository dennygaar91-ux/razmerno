# Размерно — constructor stabilized v3

## Что сделано

Стабилизирован новый static UI конструктора после стабилизации главной и информационных страниц.

## Правки

- Убраны клиентские следы разработки:
  - `Warning блокирует заявку`
  - `Preview`
  - `fallback`
  - `MVP`
  - `Активный декор должен менять preview`
- Правая сцена получила живое SVG/2D-превью шкафа внутри текущего класса `.rzm-constructor-model`.
- Выбор материала меняет атрибут `data-material` у модели и визуально перекрашивает SVG.
- Кнопки `+ / −` обновляют значения и ориентировочно меняют цену в UI.
- Добавлены:
  - расшифровка стоимости;
  - блок «Что будет после заявки»;
  - согласие на обработку персональных данных;
  - поле адреса при включении доставки;
  - success-состояние после нажатия CTA;
  - сохранение UI-черновика без PII в `localStorage`.

## Что не трогалось

- backend;
- `/api/orders`;
- pricing engine;
- delivery engine;
- admin;
- production/geometry/manufacturing logic.

## Важно

Это всё ещё static UI слой. Следующий этап — заменить временную UI-логику на подключение к Zustand/store, pricing engine и настоящему order flow.
