# Размерно — info pages stabilized v2

## Что сделано

После стабилизации главной отдельно пересобраны информационные страницы:

- `/measurements`
- `/materials`
- `/assembly`

Цель этапа — убрать визуальную монотонность, сломанные сетки и тяжёлые наслоения после прошлой попытки внедрить все предложения сразу.

## Принцип

- Не трогать backend, API, pricing, delivery, admin, production/geometry.
- Не внедрять новые тяжёлые анимации.
- Использовать текущие системные классы и добавлять только scoped-классы `.rzm-info-*`.
- Сохранять маршрутную совместимость `/measurements`, `/materials`, `/assembly`, `/configurator`.

## Что не сделано намеренно

Эти задачи лучше делать отдельными этапами после визуальной проверки стабильной базы.
