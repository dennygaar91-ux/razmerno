Cleanup удалял только CSS-правила, у которых все `.rzm-*` классы не найдены в runtime/static source и не совпадают с сохранёнными dynamic-prefix правилами. Это всё ещё требует визуальной проверки, потому что CSS cleanup может иметь визуальные edge cases.
