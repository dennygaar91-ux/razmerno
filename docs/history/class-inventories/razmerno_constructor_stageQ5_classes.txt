Stage Q5 — добавленные/изменённые классы

1. rzm-3d-shell--q5
Назначение: stage marker новой 3D-first страницы после Q5.
Блок: общий shell Constructor3DPage.
Статус: добавлен.

2. rzm-3d-fill-polish
Назначение: scope для переработанного шага «Наполнение».
Блок: drawer body шага fill.
Статус: добавлен.

3. rzm-3d-fill-empty-state
Назначение: instruction state, когда пользователь ещё не выбрал зону на 3D-модели.
Блок: шаг «Наполнение».
Статус: добавлен.

4. rzm-3d-fill-empty-icon
Назначение: визуальный круглый плюс внутри instruction state.
Блок: шаг «Наполнение».
Статус: добавлен.

5. rzm-3d-fill-section
Назначение: единый контейнер для групп шага «Наполнение».
Блок: текущий выбор, действия, фасады, zones, elements, validation.
Статус: добавлен.

6. rzm-3d-fill-section-header
Назначение: унифицированный header группы внутри шага «Наполнение».
Блок: все q5 fill sections.
Статус: добавлен.

7. rzm-3d-fill-active-meta
Назначение: компактные chips текущего выбора: секция/зона/фасад.
Блок: текущий выбор.
Статус: добавлен.

8. rzm-3d-fill-actions
Назначение: scope группы действий выбранной зоны.
Блок: действия зоны.
Статус: добавлен.

9. rzm-3d-add-menu--q5
Назначение: q5-вариант меню добавления наполнения в выбранную зону.
Блок: действия зоны.
Статус: добавлен.

10. rzm-3d-fill-hint
Назначение: короткая подсказка, если + на модели ещё не открыт.
Блок: действия зоны.
Статус: добавлен.

11. rzm-3d-fill-counters
Назначение: счётчики наполнения выбранной зоны.
Блок: элементы зоны.
Статус: добавлен.

12. rzm-3d-fill-empty-copy
Назначение: пустое состояние «В зоне пока нет наполнения».
Блок: элементы зоны.
Статус: добавлен.

13. rzm-3d-fill-check
Назначение: отдельная группа проверки выбранной зоны.
Блок: validation шага «Наполнение».
Статус: добавлен.

Изменённые существующие классы:
- rzm-3d-zone-list: используется внутри rzm-3d-fill-section, получила более понятную роль в структуре Q5.
- rzm-3d-elements-list: используется как список элементов выбранной секции/зоны.
- rzm-3d-element-row: визуально уплотнён в Q5 scope.
