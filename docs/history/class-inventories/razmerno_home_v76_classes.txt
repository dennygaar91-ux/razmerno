Размерно — главная страница v76: список классов

Принцип этапа
- Повторяющиеся элементы вынесены в общие классы: карточки, сетки, кнопки, chips, section header, FAQ, footer, material cards.
- Старые неиспользуемые секции HomePrice и HomeCustomProject удалены из src/static-pages/home, чтобы не оставлять дублирующие блоки главной.
- Расчёт, заявки, backend/API, Supabase, админка и логика конструктора не трогались.

1. Общая структура главной
- .rzm-home-main — общий контейнер main главной страницы; задаёт ширину var(--rzm-container), вертикальный rhythm и отступ от header.
- .rzm-home-section — единая оболочка светлого блока главной: padding, radius, glass-background, inset border, soft shadow.
- .rzm-home-section-head — единый layout заголовка секции: title слева, lead справа.
- .rzm-home-section-title — единый крупный заголовок секций.
- .rzm-reveal — единая reveal-анимация для блоков.

Добавлено/изменено в текущем этапе:
- .rzm-home-main изменён под финальную структуру.
- .rzm-home-section полностью стандартизирован.
- .rzm-home-section-head и .rzm-home-section-title используются как базовые классы для всех секций.

2. Текст, chips, маркеры
- .rzm-hero-lead — общий lead-текст для Hero и секций.
- .rzm-kicker — общий chip-заголовок блока.
- .rzm-kicker--dark — dark-context вариант chip в финальном CTA.
- .rzm-how-chip-title — сохранён как совместимый alias для shared SectionHeader и info pages.
- .rzm-chip-dot — единая оранжевая точка внутри chips/kicker.
- .rzm-chip-row — общий ряд chips.
- .rzm-chip — общий pill-chip для преимуществ.
- .rzm-card-text — общий текст внутри карточек.
- .rzm-step-text — сохранён как совместимый alias для старых/shared компонентов.

Добавлено/изменено в текущем этапе:
- .rzm-kicker добавлен как новый системный класс.
- .rzm-card-text добавлен как базовый класс текста карточек.
- .rzm-step-text стандартизирован, чтобы не было нескольких разных определений.

3. Кнопки и actions
- .rzm-actions — общий flex-контейнер CTA-кнопок.
- .rzm-home-actions — совместимый alias для старых компонентов, использует ту же систему.
- .rzm-secondary-cta — единая вторичная кнопка.
- .rzm-actions--dark — dark-context вариант для кнопок в тёмном CTA.
- .rzm-cta — primary CTA берётся из src/styles/header.css и переиспользуется без локальных копий.

Добавлено/изменено в текущем этапе:
- .rzm-actions добавлен как основной класс для рядов кнопок.
- .rzm-secondary-cta приведён к единому размеру, radius, hover и dark-варианту.

4. Сетки и карточки
- .rzm-card-grid — общий grid для карточек.
- .rzm-card-grid--four — grid на 4 карточки для блока «От размера до заявки».
- .rzm-card-grid--three — grid на 3 карточки для блока типов мебели.
- .rzm-process-card — карточка шага процесса.
- .rzm-product-card — карточка типа мебели.
- .rzm-feature-card — карточка пункта комплекта.
- .rzm-card-number — единый номер/маркер в карточках.
- .rzm-home-step-number и .rzm-how-step-number — совместимые aliases для существующих компонентов.
- .rzm-card-arrow — единая стрелка карточки.
- .rzm-home-card-arrow — совместимый alias для старых компонентов.
- .rzm-card-visual — общий mini-visual внутри карточки.
- .rzm-step-illustration — совместимый alias.
- .rzm-card-visual--measure — variant визуала для размеров.
- .rzm-card-visual--modules — variant визуала для наполнения.
- .rzm-card-visual--materials — variant визуала для декора.
- .rzm-card-visual--request — variant визуала для заявки.

Добавлено/изменено в текущем этапе:
- Карточки процесса, продукта, комплекта и материалов теперь используют общую базовую геометрию: radius, background, inset border, hover.
- Визуальные variants сведены к одной системе .rzm-card-visual--*.

5. Hero

- .rzm-home-hero-visual — visual-карточка Hero.
- .rzm-home-hero-photo — изображение внутри Hero.
- .rzm-visual-glow — мягкая тень/свечение под visual.
- .rzm-ui-marker — общий floating marker.
- .rzm-ui-marker--hero — variant marker в Hero.
- .rzm-ui-marker--top — позиция top/right.
- .rzm-ui-marker--bottom — позиция bottom/left.

Добавлено/изменено в текущем этапе:
- Hero переписан под финальную концепцию «Соберите мебель под свой размер — как понятный конструктор».
- Старые форматы chips «шкаф/тумба/комод» заменены на trust chips.
