Что сделано:

4. Active area на 2D-чертёже теперь строится по реальной пропорциональной высоте выбранного отсека, а не по равному делению.
5. Добавлен тест blueprintGeometry.test.ts.
6. В package.json добавлен script test:blueprint-geometry.
7. Добавлен scoped CSS R20:
   - устойчивый desktop grid;
   - защита scene toolbar от переполнения;
   - скрытие декоративных orb/floor/model shadow в 2D fallback;
   - non-scaling stroke для active area.
8. scripts/browser-smoke-static.mjs обновлён, чтобы проверять R20 stage-scope и отсутствие старых CSS-подмен текста.
