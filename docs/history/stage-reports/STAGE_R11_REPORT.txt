Stage R11 — desktop constructor visual simplification + 2D/3D split

Scope выполнен частично в рамках безопасного прохода без изменения pricing/order/API/backend:
1. Упрощён основной desktop UI конструктора: сокращены длинные пояснения в шагах «Размеры», «Наполнение», «Материалы».
2. Верхняя панель сцены разделена визуально: stepper занимает отдельный верхний уровень, controls/режимы/стоимость собраны ниже в toolbar.
