Stage R16 — materials and sidebar visual polish

Цель этапа:
Довести шаг «Материалы» и общий sidebar constructora до более спокойного production-level вида: меньше карточек, меньше текста, компактные swatches, нормальные tabs ЛДСП/МДФ, read-only строка задней стенки, единая визуальная система внутри desktop-sidebar.

Вопросы перед стартом:
Дополнительных вопросов пользователю не было. Ранее зафиксировано: desktop first, mobile не трогать, pricing/order/backend/API/Supabase не трогать, материалы показывать компактно, задняя стенка должна быть одной read-only строкой.

Планировалось:
1. Упростить шаг «Материалы».
2. Заменить крупную сетку/старые swatch-card на компактный listbox.
3. Сделать tabs ЛДСП / МДФ более похожими на нормальный segmented-control.
4. Оставить корпус только как ЛДСП 16 мм.
5. Заднюю стенку показать одной read-only строкой.
6. Убрать pricingNotice/сметную подсказку из шага «Материалы», не меняя расчёт.
7. Добавить scoped CSS-слой Stage R16, чтобы не ломать другие страницы.
8. Прогнать проверки и собрать архив.
