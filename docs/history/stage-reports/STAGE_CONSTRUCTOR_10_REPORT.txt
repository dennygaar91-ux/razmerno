Implemented:
1. Added a geometry layout metrics helper that converts constructor section widths into production inner section metrics.
2. Geometry builder now uses manual section width proportions for partitions, shelves, drawer targets, facade targets and rod targets.
3. Geometry sections can carry per-section facadeMode: open / hinged.
4. Facade builder skips open sections and builds doors only for hinged sections.
5. MDF facade panels are now marked as materialType mdf when facade thickness is 18 mm; LDSP facades stay ldsp when thickness is 16 mm.
6. Drawer fronts also use mdf/ldsp materialType based on facade thickness.
7. Order payload and order types now carry optional backPanelId/backPanelKind without changing checkout flow.
8. Constructor payload derives backPanelId centrally from the body LDSP mapping.
9. Production export from order uses backPanelId and HDF 3 mm thickness.
10. Production preview tests now cover real HDF mapping, MDF thickness and open-section facade behavior.

Known limitations:
- Pricing still does not use the new material/thickness model. This is intentionally untouched.
- Hardware/drilling remains MVP/skeleton and still requires technologist check for many operations.
- Drawer slide and rod-holder drilling is still simplified and not a final factory drilling map.
- Production snapshot is available through preview/export generation, not yet persisted as a separate store field after each action.
