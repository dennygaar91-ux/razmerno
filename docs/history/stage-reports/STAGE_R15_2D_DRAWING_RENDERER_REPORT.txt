Ошибки / ограничения:
1. npm run test:browser-smoke в sandbox не может быть подтверждён, потому что в Linux sandbox отсутствует Playwright Chromium binary.
2. npx playwright install chromium в sandbox не смог скачать браузер из-за DNS/network EAI_AGAIN cdn.playwright.dev.
3. У пользователя локально Chromium установлен, поэтому финальный browser-smoke нужно прогнать локально.
4. Визуальное качество 3D этим этапом не улучшалось — это отдельный Stage R17 после подтверждения runtime.
