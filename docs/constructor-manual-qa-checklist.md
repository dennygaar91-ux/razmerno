# Constructor manual QA checklist

Документ нужен для проверки конструктора после `npm run build` и `npm run dev`.

## 1. Сборка

```bash
npm install
npm run build
```

Ожидаемый результат:

- build проходит без ошибок;
- нет `Could not resolve import`;
- нет syntax error;
- нет падения Vite.

## 2. Локальный запуск

```bash
npm run dev
```

Открыть:

```txt
http://localhost:5173/constructor
```

Проверить в DevTools Console:

- нет красных runtime errors;
- нет бесконечных warnings;
- нет белого экрана;
- страница не перезагружается циклически.

## 3. Разрешения экрана

Проверить минимум:

```txt
1536 × 1024
1536 × 864
1440 × 900
1366 × 768
```

Для каждого разрешения проверить:

- нет горизонтального overflow;
- три колонки помещаются;
- левая панель usable;
- viewer не слишком маленький;
- правая панель не ломается;
- checkout drawer помещается и прокручивается.

## 4. Первый экран конструктора

Проверить:

- заголовок не слишком крупный;
- верхние кнопки не наезжают на текст;
- flow steps читаются;
- активный шаг понятен;
- hero не съедает слишком много высоты.

Скриншот: общий вид конструктора.

## 5. Шаг “Размеры”

Проверить:

- кнопки `+ / −` работают;
- высота не выходит за 200–2800 мм;
- ширина не выходит за 400–3000 мм;
- глубина не выходит за 300–800 мм;
- секции не выходят за 1–6;
- ширина секции пересчитывается;
- предупреждения читаются;
- кнопка “Далее: наполнение” работает.

## 6. Шаг “Наполнение”

Проверить:

- можно выбрать секцию 1 / 2 / 3;
- при изменении количества секций карта обновляется;
- presets работают:
  - Гардероб;
  - Полки;
  - Ящики;
  - Пусто;
- `Копировать в соседнюю` работает;
- `Применить ко всем` работает;
- quick actions в viewer работают:
  - Полка;
  - Ящик;
  - Штанга;
  - Очистить;
- при глубине меньше 520 мм штанга недоступна;
- active section подсвечивается в viewer и карте секций.

Скриншот: шаг “Наполнение”.

## 7. Шаг “Материалы”

Проверить:

- выбранный материал виден в “Текущая спецификация”;
- material swatch отображается;
- выбор корпуса меняет название материала в правой панели;
- выбор кромки меняет кромку в правой панели и checkout;
- выбор открывания меняет открывание;
- выбор фурнитуры меняет фурнитуру;
- бейджи `База / + ₽ / MVP` не выглядят слишком крупными;
- шаг не выглядит чрезмерно длинным на 1366×768.

Скриншот: шаг “Материалы”.

## 8. Viewer

Проверить:

- CSS preview шкафа отображается;
- нет белого блока вместо шкафа;
- подписи размеров не перекрывают шкаф критично;
- active section видна;
- карта секций не ломается при 1–6 секциях;
- быстрые сценарии в карте секций не слишком мелкие.

Если быстрые сценарии мелкие: убрать action-кнопки из карточек секций и оставить только выбор секции.

## 9. Правая панель

Проверить:

- цена видна сразу;
- CTA “В корзину” виден;
- проверка проекта читается;
- параметры не обрезаются критично;
- “Что входит” помещается;
- смета открывается и закрывается;
- раскрытая смета не ломает layout;
- на 1366×768 правая панель может скроллиться, но не должна перекрывать остальные блоки.

## 10. Сохранение / загрузка / очистка

Проверить:

1. Изменить размеры.
2. Дождаться статуса автосохранения.
3. Обновить страницу.
4. Проверить, что проект восстановился.
5. Нажать “Сохранить”.
6. Проверить notice с projectId.
7. Нажать “Загрузить”.
8. Проверить, что проект загрузился.
9. Нажать “Очистить”.
10. Проверить confirm modal.
11. Нажать “Отмена”.
12. Проверить, что проект не сброшен.
13. Нажать “Очистить” и подтвердить.
14. Проверить, что проект сброшен.

## 11. Checkout drawer

Проверить:

- открывается по “В корзину”;
- overlay затемняет страницу;
- закрывается по `×`;
- закрывается по overlay;
- закрывается по `Escape`;
- body прокручивается;
- footer остаётся доступным;
- цена и доставка считаются;
- delivery modes переключаются;
- payment modes переключаются;
- empty submit показывает ошибки;
- errors не ломают layout;
- заполненная форма создаёт заявку;
- success-state показывается.

Скриншот: checkout drawer.

## 12. LocalStorage edge cases

Проверить в DevTools Application → Local Storage:

Ожидаемые ключи:

```txt
razmerno.constructor.project.v1
razmerno.constructor.projectId.v1
razmerno.constructor.projectMeta.v1
```

После очистки эти ключи должны удалиться.

## 13. Console warnings

Допустимо:

- временные warnings от mock-service;
- warnings при намеренной ошибке сохранения/заявки.

Недопустимо:

- infinite render loop;
- cannot read property of undefined;
- failed to resolve module;
- React key warnings;
- invalid DOM nesting warnings.

## 14. Решение после проверки

Если всё хорошо:

```txt
Можно считать frontend конструктора pre-MVP готовым на 95–97%.
```

Если есть визуальные проблемы:

1. Сначала править 1366×768.
2. Потом checkout.
3. Потом SectionMap.
4. Потом CSS mockup шкафа.
5. Не добавлять новые UX-фичи до стабилизации.
