# Project Glossary — «Размерно»

Дата актуализации: 2026-06-10

## Пользовательские термины

**Секция** — вертикальная часть мебели по ширине. Пользователь видит “Секция 1”, “Секция 2” и т.д.

**Зона** — область внутри секции по высоте. Пользователь выбирает зону на 3D-модели и добавляет в неё полку, ящики или штангу.

**Наполнение** — внутренние элементы зоны: полки, ящики, штанга.

**Фасад** — внешняя закрывающая панель секции или зоны. В обычном режиме управляется на уровне секции; в точной настройке — на уровне зоны.

**Точная настройка** — расширенный режим для опытного пользователя. Включается глобально на все шаги.

**Заявка** — финальный шаг checkout внутри конструктора.

**Смета** — детализация цены в checkout.

**2D fallback** — рабочий SVG/2D режим без WebGL. Не равен инженерному чертежу.

## Технические термины

**compartment** — legacy/internal техническое имя зоны в коде. В UI использовать “зона”.

**section** — техническая секция мебели.

**module** — общий термин для мебельного/интерфейсного модуля; использовать аккуратно, чтобы не смешивать с секцией.

**canonical state** — derived read model, нормализующий constructor state для UI/3D/2D/pricing.

**pricing engine** — слой расчёта цены. Цена считается точной, прайс умножается на ×1.3.

**production warning** — технологическое предупреждение. Сложные production warnings скрываются от клиента.

**blocking error** — ошибка, блокирующая переход/заявку.

**soft warning** — предупреждение, которое не должно выглядеть как поломка продукта.

**legacy quarantine** — временное состояние старого кода `src/configurator/**`, который не является активным route, но сохраняется до миграции тестов.

**BlueprintViewer** — целевой будущий отдельный компонент 2D fallback/blueprint режима.
