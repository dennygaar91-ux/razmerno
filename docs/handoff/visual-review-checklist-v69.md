# Размерно — visual review checklist v69

## Что обязательно проверить глазами

### 1. Главная `/`

Проверить:

- hero больше не выглядит как страница только про шкаф;
- шкаф, тумба и комод считываются равнозначно;
- CTA `Открыть конструктор` не конфликтует с текстом;
- изображения из референсов не выглядят случайно вставленными;
- карточки не «поехали» на desktop/tablet/mobile;
- страница не стала слишком шумной.

Viewport:

- 1440×900
- 1280×800
- 768×1024
- 390×844

### 2. Замеры `/measurements`

Проверить:

- hero с фото и линиями размеров читается;
- ширина / высота / глубина не конфликтуют визуально;
- блоки подготовки и сложных мест выглядят как помощь, а не как перегруз;
- checklist на mobile не слишком длинный.

### 3. Материалы `/materials`

Проверить:

- 7 декоров выглядят нейтрально и мебельно;
- оранжевый не выглядит как материал мебели;
- swatches не слишком декоративные;
- фото не конфликтуют с палитрой;
- active state понятен.

### 4. Сборка `/assembly`

Проверить:

- страница не выглядит как абстрактная инструкция;
- flat-lay / комплект деталей считывается;
- timeline не слишком длинный;
- блок `Если что-то не сходится` достаточно строгий.

### 5. Конструктор `/configurator`

Проверить desktop:

- scene не конфликтует с sidebar;
- 3D / 2D переключатель виден;
- `Свободно / Спереди / Сбоку / Сверху` видны и кликабельны;
- OrbitControls реально работает в режиме `Свободно`;
- SVG fallback в `2D` выглядит приемлемо;
- labels ширина/высота/глубина не перекрывают модель;
- footer chips не слипаются;
- sidebar current step помогает, а не шумит;
- checkout стал читаемее.

Проверить mobile 390×844:

- сцена не занимает слишком много высоты;
- stepper горизонтально скроллится;
- sticky submit не перекрывает поля;
- 3D не тормозит;
- reduced quality не выглядит слишком бедно;
- 2D fallback доступен.

### 6. Three.js states

Проверить:

- WebGL available → 3D открывается;
- 2D → SVG fallback;
- `Свободно` → можно вращать;
- `Спереди` → фронтальный вид;
- `Сбоку` → боковой вид;
- `Сверху` → верхний вид;
- при ошибке 3D сцена не ломает страницу.

## Что не оценивать как финальное

Пока не считать финальными:

- точность света в Three.js;
- реалистичность материалов;
- production-grade геометрию;
- exploded view;
- assembly animation;
- pixel-perfect spacing на всех экранах.
