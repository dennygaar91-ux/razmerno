# Price update runbook

## Когда использовать

При новом прайс-листе поставщика или изменении услуги/стоимости.

## Правило цены

Все импортируемые цены должны сохраняться с наценкой:

```txt
retailPrice = sourcePrice × 1.30
```

## Порядок обновления

1. Положить новый Excel-прайс рядом с проектом.
2. Обновить importer/seed, если структура листов изменилась.
3. Пересобрать seed:

```bash
npm run build:price-seed
```

4. Проверить целостность:

```bash
npm run check:price-integrity
```

5. Прогнать полный QA:

```bash
npm run qa:all
```

6. После успешной проверки применить SQL:

```sql
-- сначала db/pricing.sql
-- затем db/seed/price-items.sql
```

## Что проверяет integrity-check

- `price-items.json`, `price-items.jsonl`, `price-items.sql` существуют.
- Количество строк seed и jsonl совпадает.
- У всех позиций есть обязательные поля.
- Наценка `1.3` применена корректно.
- Нет дублей по ключевым атрибутам.
- Есть достаточное количество категорий:
  - board;
  - edge;
  - service.
- SQL seed содержит ожидаемую структуру.

## Важно

Если прайс изменится по структуре, нельзя просто заменить файл. Нужно проверить импорт и убедиться, что Egger/Kronospan/кромка/услуги не потерялись.
