# Размерно — full clickable static site v1

Состав:
- `index.html` — главная
- `measurements.html` — Замеры
- `materials.html` — Материалы
- `assembly.html` — Сборка
- `constructor.html` — кликабельный конструктор
- `assets/` — изображения

## Что кликабельно
- Header/nav между страницами
- CTA на конструктор
- В конструкторе:
  - шаги Размеры / Наполнение / Материалы / Заявка
  - тип мебели
  - +/- в размерах
  - +/- в наполнении
  - выбор наполнения
  - выбор ручек
  - выбор материала
  - toggles

## Как запустить
```powershell
cd путь_к_папке
python -m http.server 5173
```

Открыть:
```text
http://localhost:5173
http://localhost:5173/constructor.html
```

## Как переносить в общий проект
Эта версия подготовлена как static prototype. При переносе в React/Vite:
- HTML-блоки переносить в компоненты страниц.
- CSS-классы можно оставить как базовую дизайн-систему.
- JS из `constructor.html` заменить на состояние React/Zustand.
- Значения размеров, материалов, наполнения, цены и заявки подключить к общей бизнес-логике и backend.
- Текущие цены/значения в HTML являются UI-заглушками.

## Важно
- Это кликабельный UI-прототип, не production-логика.
- Расчёт цены, валидации, сохранение заявки, email и backend нужно подключать отдельно.
